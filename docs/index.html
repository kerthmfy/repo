Add to Cydia

If Cydia warns that the source is unsigned, tap Add Anyway. The packages themselves are still installed normally.

  1. 1Open Cydia and choose Sources.
  2. 2Tap Edit, then Add.
  3. 3Enter the source above, tap Add Source, then search for the app.
